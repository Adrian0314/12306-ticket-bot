# 12306 高铁票订票助手

基于 Selenium + CDP（Chrome DevTools Protocol）的 12306 查票 / 订票脚本。

> ⚠️ **免责声明**：本项目仅供个人学习参考，请勿用于商业用途或规模化抢票。使用本脚本产生的任何后果由使用者自行承担。

## 功能

- 浏览器扫码登录，自动检测登录状态
- 多订单批量配置，同线路自动合并
- 两种抢票模式：按起售时间 / 登录后统一倒计时
- CDP 监听查票接口（兼容 `queryG` 等轮换端点），直接解析原始 JSON，比 DOM 解析更快更稳
- 席别、出发时段筛选；**只选目标席别有票的车次**；查票失败自动重试
- 静音车厢自动勾选（车次支持时），规则说明弹窗自动关闭
- 优先选座（A/B/C/D/F，二等座无 E 座），车次不支持选座时自动跳过
- 学生票提示弹窗、资质核验弹窗自动处理
- **人工确认模式（默认）**：脚本自动完成选人 / 选席别 / 选座 / 勾静音车厢后停在确认框前，付款动作永远由人工完成
- 订单数据独立配置，主脚本不含任何个人信息

## 环境要求

- Python 3.8+
- Chrome 浏览器
- 12306 账号（需扫码登录）

## 安装

```bash
pip install selenium
```

## 使用方法

1. 复制 `config.example.json` 为 `config.json`（`config.json` 已被 `.gitignore` 排除，不会误提交个人信息）
2. 在 `config.json` 里填入你的订单（出发站、到达站、日期、乘车人）及功能开关
3. 运行：

```bash
python ticket_bot_v4.py
```

4. 浏览器打开 12306 登录页，手机 App 扫码登录
5. 脚本自动按配置查票、选人、选席别、勾静音车厢、选座
6. 停在订单确认框前：**人工核对后手动点击“确认”**，随后手动完成支付
7. 回终端按回车，继续下一笔订单

## 配置说明

`config.json` 字段含义：

| 字段 | 说明 |
|------|------|
| `mode` | `"sale_time"` = 每笔订单按起售时间抢；`"timer"` = 登录后统一倒计时 |
| `delay_seconds` | `timer` 模式下登录后等待的秒数 |
| `debug_seat` | `true` = 点预订后暂停，人工查看选座界面 |
| `mute_car` | `true` = 勾选静音车厢（车次支持时） |
| `preferred_seat` | 首选座位字母 `A/B/C/D/F`（二等座无 E），留空 `""` = 不选座 |
| `auto_submit` | `false`（默认）= 停在确认框前人工确认；`true` = 自动确认提交 |
| `orders` | 订单列表，每笔一个对象 |
| `enabled` | `true` = 抢这单 / `false` = 跳过 |
| `from_st` / `to_st` | 出发 / 到达站名（中文） |
| `date` | 出发日期，格式 `YYYY-MM-DD` |
| `sale_time` | 起售时间，格式 `HH:MM`（`sale_time` 模式生效；已过则顺延次日，超 6 小时视为已过直接查） |
| `depart_time_range` | 出发时段，如 `"08:00-12:00"`；留空 = 不限时段 |
| `seat_type` | 席别：二等座 / 一等座 / 商务座 / 硬座 / 无座 |
| `passengers` | 乘车人列表，`name` 必须与 12306 常用联系人一致 |

## 原理

1. Selenium 启动真实 Chrome，扫码登录 12306
2. CDP 监听查票接口响应（`leftTicket/query*`，兼容端点轮换），毫秒级拿到原始 JSON
3. 按配置过滤车次（时段 + 目标席别必须有票）
4. 下单走浏览器自动化：选人 → 处理学生票弹窗 → 选席别 → 点提交订单 → 确认框内勾静音车厢、选座 → 停在确认前人工确认

- 起售等待支持跨天（深夜跑等次日凌晨起售），已过 6 小时视为已过直接查询
- 关键异常处补充完整 traceback 日志
- 新增静音车厢勾选、优先选座、学生票弹窗 / 静音车厢说明弹窗 / 资质核验弹窗自动处理
- 新增人工确认模式（`auto_submit: false`）：脚本停在确认框前，确认与支付由人工完成
